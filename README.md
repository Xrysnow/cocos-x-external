# cocos-x-external

Third-party dependencies for [cocos-x](https://github.com/Xrysnow/cocos-x).
Versions below describe bundled sources or pinned snapshots, not the latest upstream
release shown by the badges.

See [BUILD.md](BUILD.md) for build integration and platform-specific dependency selection.

License summaries below refer to the corresponding bundled notices; individual
components can carry additional notices in their source files.
